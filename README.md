# Portfólio de Ezequiel Cruz

Site estático preparado para **https://ezequielcruz4.github.io/**.

## Estrutura no GitHub

Repositório: `EzequielCruz4/ezequielcruz4.github.io`.

Na raiz da branch `main`, mantenha `index.html`, `.nojekyll` e a pasta `assets/`. No projeto de origem, esses arquivos ficam dentro de `dist/`. Envie o conteúdo dessa pasta, preservando os nomes.

Em **Settings → Pages**, selecione **Deploy from a branch**, branch **main**, pasta **/(root)** e salve. Aguarde o GitHub concluir a publicação e consulte o endereço exibido nessa página.

## Atualizar

- Projetos: `assets/content.js`.
- Apresentação: `index.html`.
- Visual e animações: `assets/style.css`.
- Interações: `assets/app.js`.

O site funciona sem instalação de dependências. As prévias são recriações para apresentação; os estudos de caso indicam a contribuição de Ezequiel e os limites de cada projeto.

[Documentação oficial do GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site).
